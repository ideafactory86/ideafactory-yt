아이디어팩토리(IdeaFactory) 공식 제작 안드로이드 독립형 부스터
3단계 오가닉 키워드 검색 · 인간형 엄지 궤적 스크롤 · 비행기모드 LTE/5G IP 자동 로테이션

📥 아이디어팩토리 정식 앱(APK) 다운로드 💻 [PC 연결용] 원클릭 '제한된 설정'·비행기모드 1초 자동해제기 (.bat) 💬 아이디어팩토리 문의하기 (라이선스 발급·상담)

🚨 불법 복제 · 무단 공유 · 위변조 강력 법적 대응 안내

  • 1. 라이선스 입력 및 기기 고유번호(HWID) 중앙 서버 실시간 기록
    본 프로그램은 아이디어팩토리 마스터보드 중앙 보안 서버와 실시간 연동됩니다. 모든 라이선스 키 입력 시도, 기기 고유 식별번호(HWID), 통신사 공인 IP 및 접속 일시가 중앙 서버에 자동 입력·기록됩니다.
  • 2. APK 위변조 · 크랙 · 무단 복제 시 개발자에게 즉시 코드 자동 전송
    APK 리패키징(SHA-256 전자서명 변조), 디컴파일, 메모리 후킹(Frida/Xposed), 디버거 연결 또는 허용 대수를 초과한 무단 복제 감지 시 위변조 탐지 코드(SEC-SIG-TAMPER / SEC-CLONE-LIMIT)와 해당 기기의 HWID·공인 IP·단말기 정보가 개발자 마스터보드 서버로 즉시 자동 전송됩니다.
  • 3. 무관용 원칙 영구 차단 및 민·형사상 법적 조치
    불법 복제 및 무단 공유 적발 시 사전 경고 없이 해당 라이선스와 연관 기기가 즉시 영구 차단되며, 저작권법 및 컴퓨터프로그램보호법 위반에 따른 민·형사상 법적 조치가 진행됩니다.

📱 스마트폰(갤럭시·공기계) 3단계 설치 방법

  • 1단계 (앱 설치): 위 파란색 [아이디어팩토리 정식 앱(APK) 다운로드] 버튼을 터치해 파일을 열고, "출처를 알 수 없는 앱" 안내가 뜨면 [설정 → 이 출처 허용] 후 설치합니다. (Play 프로텍트 창이 뜨면 [세부정보 더보기 → 무시하고 설치] 선택)
  • 2단계 (정품 라이선스 인증): 앱을 실행하고 발급받은 아이디어팩토리 정품 라이선스 키를 입력하여 기기 등록을 완료합니다.
  • 3단계 (비행기모드 자동전환 & '제한된 설정' 해제): 상단 [⚡ 비행기모드 권한설정] 버튼을 눌러 접근성 설정에서 [아이디어팩토리 비행기모드 자동전환]을 켜주시면 24시간 무인 가동이 시작됩니다.
    💡 휴대폰에서 '제한된 설정' 안내가 뜰 때: 확인을 누른 뒤 앱 상단의 초록색 [🔓 제한해제 직행] 버튼을 누르면 앱 상세정보로 바로 이동합니다. 화면 우측 상단 [ ⋮ (점 3개) → 제한된 설정 허용 ]을 한 번만 눌러주시면 즉시 해제됩니다!
    💻 휴대폰에서 해제가 안 되는 경우 (PC 원클릭 1초 자동해제):
    위 초록색 [💻 PC 연결용 원클릭 '제한된 설정'·비행기모드 1초 자동해제기 (.bat)] 파일을 PC에 다운로드한 뒤, 휴대폰을 PC에 USB 케이블로 연결하고 실행(더블클릭)하시면 휴대폰 터치 없이 1초 만에 제한 해제와 비행기모드 권한이 100% 자동으로 세팅됩니다! (※ 휴대폰 [설정 → 개발자 옵션 → USB 디버깅]을 켜고 연결 후 실행해 주세요)
